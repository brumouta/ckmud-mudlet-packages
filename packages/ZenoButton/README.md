# ZenoButton

Shortcuts for the **Zeno Button**. Type `zb help`.

| Alias | Sends |
|---|---|
| `pb` | `press button` |
| `pbe` | Earth: `recall`, `press button`, `s`, `s`, `enter vortex` |
| `pbv` | Vegeta: `recall`, `press button`, `s`, `e`, `e`, `enter vortex` |
| `pbn` | Namek: `recall`, `press button`, `s`, `w`, `w`, `enter vortex` |
| `pbk` | Konats: `recall`, `press button`, `n`, `e`, `e`, `enter vortex` |
| `pbi` | Iceria: `recall`, `press button`, `n`, `w`, `w`, `enter vortex` |

`recall` takes you to King Kai's Planet and the button to the Grand Atrium, where each planet's
vortex is a few steps away.

It replaces the old **Zeno Button** module: when the package loads it takes that module out of
the profile, so the commands aren't sent twice. The module's file is left alone.
