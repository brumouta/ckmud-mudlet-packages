# Buffs

By **Penguin**. Keeps your buffs up: casts the ones you choose, recasts each one when it wears
off, and shows how long each has left in a small window. Type `autobuff help`.

| Command | What it does |
|---|---|
| `autobuff on\|off` | Turn auto-buffing on or off |
| `autobuff add <skill>` / `autobuff remove <skill>` | Choose which buffs to keep up |
| `autobuff` (or `autobuff list`) / `autobuff buffs` | Show your list / every buff it knows |
| `autobuff cast` | Cast everything on your list now |
| `autobuff newbuff <skill> :: <expire message>` / `autobuff delbuff <skill>` | Add or remove a buff it doesn't know yet |
| `autobuff setcast`, `setaffects`, `setcmd`, `setitem`, `settag`, `combat` | Fine-tune a buff (see `autobuff help`) |
| `buffwnd [show\|hide\|float]` | The buff timer window |
| `buffwnd font <size>` | The window's font size (6 to 30, default 9), kept across restarts |

Knows Energy Shield, Zanzoken, Regenerate, Swiftness, Gigantification, Hasshuken, Herculean
Force, Resonance, Hakai Barrier, Forcefield, Barrier, Infravision, Invigorate, Kino Tsurugi,
Wrathful Fury, Demonic Will, Celestial Shield, Divine Judgement, Celestial Drain, Tremor Pulse,
Kenjutsu and Protection Ballad. Recasts after a copyover too.
